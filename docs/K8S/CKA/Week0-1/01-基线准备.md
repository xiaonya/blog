# Week 0 · 基线准备

> 阶段：起步 ｜ 预计时长：2–3 小时 ｜ 目标：环境就绪、效率工具配好、建立考纲认知、自测基础

## 本周目标
- 让本地/集群环境可用，能稳定跑 `kubectl`
- 配好考试级效率工具（别名、自动补全），从第一天就省时间
- 把官方 CKA 考纲当作全程目录，建立"按域查漏"的习惯
- 自测当前水平，明确哪些是弱项

## 知识点与说明
### 1. 认识 CKA 考试形式
- 2 小时、15–20 道实操题、66 分及格、远程在线监考。
- 考试环境是一个 Linux 终端，已装好 `kubectl`；可查阅 `kubernetes.io/docs`（仅限官方域名）。
- 考纲五大域权重：集群架构/安装/配置 25%、工作负载/调度 15%、服务/网络 20%、存储 10%、排障 30%。
- **不依赖任何"真题/题库"**——CNCF 保密协议明确禁止，违规可撤销认证。

### 2. kubectl 效率三件套
- **别名**：`k=kubectl`，省一半击键。
- **命令补全**：`source <(kubectl completion bash)`，记不住参数时 Tab 补全。
- **命令式生成 YAML**：`--dry-run=client -o yaml`，考试几乎不手写 YAML。

## 学习要点与易错点
- 别名要写进 `~/.bashrc` 才会持久；考试环境也可临时配置（但你平时就要养成习惯）。
- `--dry-run=client`（不是 `none`，老版本写法已弃用）。
- 官方文档检索速度是及格关键：平时就用 docs 查，别用百度。

## 实践任务（你的集群上做）
1. 配置 `~/.bashrc`：
   ```bash
   alias k='kubectl'
   alias kgp='kubectl get pods'
   alias kgn='kubectl get nodes'
   alias kga='kubectl get all'
   alias kd='kubectl describe'
   source <(kubectl completion bash)
   ```
2. 验证集群：`k get nodes`、`k get pods -A` 都能正常返回。
3. 打开官方考纲页面（搜 `CNCF CKA Curriculum`）并存书签，浏览五大域。
4. 自测（不看文档）：
   - `kubectl create deployment nginx --image=nginx`
   - `kubectl expose deployment nginx --port=80 --type=NodePort`
   - `kubectl exec -it <pod> -- sh`
   - 不会的标出来，后续对应周次补。
