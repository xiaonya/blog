CKA 备考总览

集群状态：✅ 三节点 Ready（2026-08-09 搭建完成，见 03-集群初始化.md） 目标：CKA 认证（Kubernetes Administrator），官方认证考试，机考实操 环境：Master 192.168.10.12（本机练习环境） 官方参数核实：2026-10-18（来源：Linux Foundation CKA 考试页 + LF 认证 FAQ）

〇、重要前提：考试环境 ≠ 本地环境​

  • CKA 考试是浏览器里的虚拟环境（官方提供的集群 + 终端），不是本机
  • 本地环境配置（补全/alias）考试里不提供，但练习时能大幅提升效率，值得配
  • 本地准备的核心价值：① 练熟 kubectl 命令肌肉记忆；② 熟悉考点对应的知识点

3. 环境配置（留档）​

bash 补全 —— 已配：

kubectl completion bash > /etc/bash_completion.d/kubectl
echo 'source /usr/share/bash-completion/bash_completion' >> ~/.bashrc

alias —— 目前只有 k，完整别名组（可选，配了更省时间）：

cat >> ~/.bashrc <<'EOF'
alias kg='kubectl get'
alias kd='kubectl describe'
alias kl='kubectl logs'
alias kaf='kubectl apply -f'
alias kdel='kubectl delete'
EOF
source ~/.bashrc

注意：补全和 alias 考试环境里都没有，练的是自己的肌肉记忆，别依赖 shell 配置答题。

一个容易混淆的点：官方页面的 Curriculum 链接仍指向 CKA_Curriculum_v1.35.pdf，但考试环境标注已是 v1.37。 也就是说权重表还是 v1.35 版的内容，跑的环境已经是 v1.37。考点范围按权重表准备，具体对象行为以 1.37 文档为准。

本地练习环境与考试的版本差​

  • 本地：v1.36.3 ｜ 考试：v1.37（差一个小版本）
  • 对 CKA 影响很小：考的 API 对象（Pod/Deployment/Service/PV/PVC/NetworkPolicy/RBAC）跨版本稳定
  • 需要留意的只是被移除或改默认值的字段。考前花 1 小时过一遍 1.37 的 release notes 中 Removed 和 Changed 段即可，不必升级集群
  • 如果坚持对齐：kubeadm upgrade plan → 逐节点升级，属于 Week 0-1 学过的内容，可以当复习

领域权重表（Curriculum v1.35，权重未变）​

故障排除为最高权重 30%，架构/安装合并为 25%，工作负载 15%。前期笔记里 20%/10% 的旧权重已作废。

领域权重核心考点
集群架构、安装和配置25%RBAC、kubeadm 建集群、集群生命周期（升级）、高可用控制平面、Helm/Kustomize、扩展接口（CNI/CSI/CRI）、CRDs 和 Operators
工作负载和调度15%Deployment 滚动更新/回滚、ConfigMap/Secret、自动扩缩容、自愈部署、Pod 准入和调度（limits/node affinity/taint）
服务和网络20%Pod 连通性、NetworkPolicy、Service（ClusterIP/NodePort/LoadBalancer）+ Endpoints、Gateway API、Ingress 控制器/资源、CoreDNS
存储10%StorageClass 动态供给、卷类型/访问模式/回收策略、PV/PVC 管理
故障排除30%集群/节点排障、组件排障（apiserver/etcd/kubelet）、资源监控、容器输出流、服务与网络排障

重点：

  • 故障排除 30% 权重最高，考试会把集群搞坏让你修（Pod CrashLoopBackOff、节点 NotReady、DNS 不解析等）
  • etcd 备份恢复 在架构域必考，考试大纲明确列出
  • 新版考纲新增：Gateway API、CRDs/Operators、Helm/Kustomize（注意别漏）

二·1、考试 open-book 规则（可查阅内容）​

CKA 是开卷考，但只能查特定官方资源：

可查阅说明
kubernetes.io/docs官方文档，最大依仗，Tasks 章节有逐步操作步骤
kubernetes.io/blog官方博客
github.com/kubernetesK8S 官方 GitHub

限制：

  • 只能开 1 个额外浏览器标签页，只允许访问上面三个域名
  • 搜索引擎、其他博客、AI 工具等一律不可用
  • → 平时练好"去 kubernetes.io/docs 查具体步骤"的习惯，考试时这就是救命稻草
  • 官方原文清单：docs.linuxfoundation.org/tc-docs/certification/certification-resources-allowed（考前以它为准）

三、学习路径规划​

基于当前进度（集群已就绪），推荐顺序：

  1. 配好本地环境（第一节，10 分钟）
  2. 第一个实验：Deployment + Service + Ingress——打通"应用跑起来→对外暴露"主线
  3. 排障练习：删 coredns 重建、cordon/uncordon 节点、kubectl describe 找问题
  4. etcd 备份恢复（CKA 必考、权重高、唯一集群级操作）
  5. 刷模拟题：CKA 模拟题巩固 + 查漏补缺

四、CKA 考试实用技巧​

  • 官网资源：kubernetes.io/docs 是考试时唯一可查的官方资料（含任务章节操作步骤），必须熟练使用
  • 每题先读题干 → 找到对应 namespace → 用 kubectl 快速创建，避免手写长 YAML（多用 kubectl create/run 生成骨架再改）
  • 时间分配：官方不公布题量，按 120 分钟倒排。排障题 30% 权重、通常最耗时，先做完能立刻上手的题，把排障留出足够余量
  • 考试界面有 Notepad 和 Calculator 内嵌工具，关键信息（IP、namespace）随手记
  • 提交前用 kubectl get 验证答案生效
