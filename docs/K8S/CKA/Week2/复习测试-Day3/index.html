复习测试 · Day 3（Namespace）

闭卷，15 分钟，满分 50 分。60% 以上算过关。

一、填空题（每空 2 分，共 20 分）​

  1. Kubernetes 有四个内置 Namespace：、、、。

  2. 不指定 -n 时，kubectl 默认操作的 namespace 是 ________。

  3. 查看所有 namespace 下的 Pod，使用的参数是 ________。

  4. 删除一个 Namespace 时，里面的所有资源会 ________。

  5. kubectl get pods -l env=prod --all-namespaces 的输出中，default namespace 的 Pod 也被筛出来了，说明 --all-namespaces 的行为是 ________。

  6. Service 的 selector 只能匹配 ________ 的 Pod。

  7. 不受 namespace 约束的三种资源：、、________。

  8. PersistentVolume 不在 namespace 里，但 ________ 在 namespace 里。

  9. Namespace 和 Label 的核心区别：Namespace 是 ________ 隔离，Label 是 ________ 分类。

  10. 查看某个 Service 是否找到了后端 Pod，应该看 ________ 资源。

二、判断题（每题 2 分，共 10 分）​

  1. （ ）Namespace 可以嵌套，即一个 Namespace 里可以再建子 Namespace。

  2. （ ）两个不同 namespace 里的 Pod 可以有完全相同的名字。

  3. （ ）删除 Namespace 只删除 Namespace 本身，里面的 Pod 需要单独删除。

  4. （ ）kubectl get pods -l env=prod 不加 -n 时，会搜索所有 namespace 中有 env=prod label 的 Pod。

  5. （ ）kubectl get pods --all-namespaces -l env=prod 等价于在每个 namespace 里分别跑 kubectl get pods -l env=prod。

三、简答题（每题 5 分，共 10 分）​

  1. 你执行 kubectl expose pod web-prod --port=80 -n default 报 NotFound，但 kubectl get pods --all-namespaces 能看到 web-prod 在 prod namespace。请说明原因和正确做法。

  2. 用一句话说清 Namespace 和 Label 的区别，并各举一个使用场景。

四、实操题（10 分）​

在集群上完成以下操作（写出命令序列）：

  1. 创建 namespace test-ns（2 分）
  2. 在 test-ns 中创建一个 nginx Pod，并打上 app=web 的 label（3 分）
  3. 为该 Pod 创建一个 Service（2 分）
  4. 验证 Service 有 endpoints（1 分）
  5. 删除 test-ns，并验证 Pod 和 Service 都被级联删除了（2 分）

参考答案​

点击展开

填空题​

  1. default、kube-system、kube-public、kube-node-lease
  2. default
  3. --all-namespaces（或 -A）
  4. 被级联删除（一起删除）
  5. 先跨所有 namespace 捞 Pod，再按 label 过滤
  6. 同一 namespace
  7. Node、PersistentVolume、Namespace（或 StorageClass、CRD 等）
  8. PersistentVolumeClaim（PVC）
  9. 物理隔离 / 逻辑分类
  10. Endpoints（或 EndpointSlice）

判断题​

  1. ✕ — Namespace 不可嵌套
  2. ✓ — 不同 namespace 的资源互相隔离，同名不冲突
  3. ✕ — 级联删除，所有子资源一起删
  4. ✕ — 不加 -n 只搜 default namespace，不是全部
  5. ✓ — --all-namespaces 就是遍历所有 namespace 再筛选

简答题​

  1. web-prod 在 prod namespace，命令用 -n default 去 default namespace 找，当然 NotFound。正确做法：kubectl expose pod web-prod --port=80 -n prod。Service 只能引用同 namespace 的 Pod。

  2. Namespace 是物理隔离（墙），用于将集群划分为互不可见的逻辑区域；Label 是逻辑分类（贴纸），用于在同一视图内筛选资源。场景：Namespace — 环境隔离（dev/prod）；Label — Service 选择后端 Pod。

实操题​

kubectl create namespace test-ns
kubectl run web --image=nginx:1.27 -n test-ns --labels=app=web
kubectl expose pod web --port=80 -n test-ns
kubectl get endpoints web -n test-ns
kubectl delete namespace test-ns
kubectl get pods -n test-ns    # 应返回 No resources found
