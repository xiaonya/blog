# 导读

本笔记主要用于记录k8s的学习过程，包括一些基础概念，常用命令，常见问题等，后续会不断更新。目标是通过这个学习笔记，能够帮助自己更好地理解k8s，同时也希望能够在熟练后能够考个cka的证书来证明自己，也有利于自己后续的就业和职业发展。

说明一下：CKA 这部分的学习计划、周次安排和大部分章节都是在 AI 辅助下制定整理的，实践环节是我自己在集群上动手做的。计划里的时间安排和考点分析可以当参考，考试细节还是以官方文档为准。

## 栏目内容

- 入门基础概念：集群里有哪些组件、对象怎么组织、网络和存储怎么走，先过一遍有个印象
- CKA 备考笔记：学习计划加按周记录的学习过程，每周有实操记录和复习测试
- 命令速查：平时用到的 kubectl 命令，按场景记的

## 学习顺序

1. 先看入门基础概念，知道集群里有哪些东西
2. 按周推进 CKA 的学习，每周在集群上做实验，做完做一份闭卷测试
3. 命令忘了就查命令速查
4. 考纲、考试形式、备考策略看 CKA 备考总览

CKA 的计划和进度记在 [CKA 学习计划](./CKA/00-CKA学习计划.md) 里，考纲和考试细节在 [CKA 备考总览](./CKA/01-CKA备考总览.md)。
